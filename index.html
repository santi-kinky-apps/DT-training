Personalizado
Actívalo para elegir tú mismo el tiempo y las repeticiones en Entrenar, Compás y Toque rápido, en vez de seguir un día fijo. Cada pantalla tiene sus propios campos para definirlo.
Entrenamiento perfecto
Si se activa, un fallo reinicia el conteo: debes lograr todas las repeticiones seguidas, sin fallar ninguna, para completar el entrenamiento. También afecta Compás: si fallas un golpe, la ronda se reinicia desde cero.
Entrenamiento continuo
Después de cada repetición tienes un tiempo límite para volver a presionar, en cualquier modo. Si se te acaba, la siguiente repetición se marca como fallada.
